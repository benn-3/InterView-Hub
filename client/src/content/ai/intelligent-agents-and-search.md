# Intelligent Agents, State-Space Search, and Heuristic Algorithms

In Artificial Intelligence, an **intelligent agent** is an autonomous entity that perceives its environment through sensors, processes information, and acts upon that environment using actuators according to a performance metric.

---

## 1. PEAS Framework for Intelligent Agents

Every AI agent architecture is formally specified via **PEAS**:
- **Performance Measure:** The objective criterion for measuring success (e.g., safety, speed, profit, accuracy).
- **Environment:** The domain in which the agent operates (observable vs. partially observable, deterministic vs. stochastic, static vs. dynamic, discrete vs. continuous).
- **Actuators:** Mechanisms through which actions are executed (e.g., robotic joints, screen displays, API triggers).
- **Sensors:** Input devices capturing environmental state (e.g., cameras, LIDAR, keystrokes, audio sensors).

### Agent Architectures
1. **Simple Reflex Agents:** Select actions based solely on current percept using condition-action rules ($if-then$).
2. **Model-Based Reflex Agents:** Maintain internal state to handle partially observable environments.
3. **Goal-Based Agents:** Combine state knowledge with explicit target goals to guide action sequences.
4. **Utility-Based Agents:** Maximize an internal utility function evaluating the desirability of competing outcomes.
5. **Learning Agents:** Decouple learning element (improving performance) from execution element (selecting actions).

## 2. Uninformed (Blind) vs. Informed (Heuristic) Search

```
Search Problem Formulation:
- Initial State: S_0
- Actions(s): Permissible transitions from state s
- Transition Model Result(s, a): Next state s'
- Goal Test: Is s in G?
- Path Cost c(s, a, s'): Non-negative cost of transition
```

| Algorithm | Strategy | Time Complexity | Space Complexity | Complete? | Optimal? |
|---|---|---|---|---|---|
| **Breadth-First Search (BFS)** | Shallowest node first (FIFO Queue) | $O(b^d)$ | $O(b^d)$ | Yes (if $b < \infty$) | Yes (if cost=1) |
| **Depth-First Search (DFS)** | Deepest node first (LIFO Stack) | $O(b^m)$ | $O(bm)$ | No (infinite loops) | No |
| **Uniform Cost Search (Dijkstra)** | Lowest path cost $g(n)$ (Min-Heap) | $O(b^{1 + \lfloor C^* / \epsilon \rfloor})$ | $O(b^{1 + \lfloor C^* / \epsilon \rfloor})$ | Yes | Yes |
| **A\* Search** | Minimum $f(n) = g(n) + h(n)$ | Exponential (depends on heuristic) | $O(b^d)$ | Yes | **Yes** (if admissible) |

## 3. A* Search Algorithm and Admissibility

A* computes total estimated path cost through node $n$:
$$f(n) = g(n) + h(n)$$
- $g(n)$: Exact cost incurred from initial state to node $n$.
- $h(n)$: Estimated cost from node $n$ to the nearest goal state.

### Optimality Requirements
1. **Admissibility (Tree Search):** The heuristic never overestimates actual cost to goal:
   $$0 \le h(n) \le h^*(n)$$
2. **Consistency / Monotonicity (Graph Search):** For every node $n$ and successor $n'$ generated by action $a$:
   $$h(n) \le c(n, a, n') + h(n')$$
   Consistency guarantees that the first time A* expands a state, the shortest path to that state has been discovered.

### Python Implementation of A* Search

```python
import heapq

def a_star_search(graph, start, goal, heuristic_fn):
    """
    Finds the optimal path between start and goal using A* Search.
    graph: Dict[Node, List[Tuple[Node, Cost]]]
    heuristic_fn: Callable[[Node], float]
    """
    # Priority queue stores (f_cost, g_cost, current_node, path)
    open_set = []
    heapq.heappush(open_set, (heuristic_fn(start), 0, start, [start]))
    
    # Track lowest g_score recorded for each state
    g_scores = {start: 0}
    visited = set()

    while open_set:
        f_cost, g_cost, current, path = heapq.heappop(open_set)

        if current == goal:
            return path, g_cost

        if current in visited:
            continue
        visited.add(current)

        for neighbor, edge_cost in graph.get(current, []):
            tentative_g = g_cost + edge_cost
            
            if neighbor not in g_scores or tentative_g < g_scores[neighbor]:
                g_scores[neighbor] = tentative_g
                f_score = tentative_g + heuristic_fn(neighbor)
                heapq.heappush(open_set, (f_score, tentative_g, neighbor, path + [neighbor]))

    return None, float('inf') # No path found
```

## 4. Adversarial Search: Minimax and Alpha-Beta Pruning

In multi-agent zero-sum games (e.g., Chess, Go, Tic-Tac-Toe), Max maximizes utility while Min minimizes it.

```
Minimax Decision Rule:
- Max_Value(s) = max_{a in Actions(s)} Min_Value(Result(s, a))
- Min_Value(s) = min_{a in Actions(s)} Max_Value(Result(s, a))
```

### Alpha-Beta Pruning
Prunes subtrees that cannot influence the final root decision:
- $\alpha$: Highest value found so far for Max along the path.
- $\beta$: Lowest value found so far for Min along the path.
- **Pruning condition:** When $\alpha \ge \beta$, stop exploring children (prune branch).
- **Efficiency:** Reduces time complexity from $O(b^m)$ to $O(b^{m/2})$ with optimal move ordering.
