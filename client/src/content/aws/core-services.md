# AWS Core Cloud Architecture & Services

Amazon Web Services (AWS) is the world's most comprehensive cloud computing platform. Here are the core services required for technical interviews.

---

## 1. Compute Services

- **Amazon EC2 (Elastic Compute Cloud):** Resizable virtual machines in the cloud.
- **AWS Lambda:** Serverless event-driven compute engine (runs code without provisioning or managing servers).
- **Amazon ECS / EKS:** Elastic Container Service and Elastic Kubernetes Service for container orchestration.

---

## 2. Storage Services

- **Amazon S3 (Simple Storage Service):** Highly scalable object storage with 99.999999999% (11 9's) durability.
- **Amazon EBS (Elastic Block Store):** High-performance block storage volumes attached to EC2 instances.
- **Amazon EFS (Elastic File System):** Serverless, fully elastic network file system shared across multiple EC2 instances.

---

## 3. Database Services

- **Amazon RDS (Relational Database Service):** Managed MySQL, PostgreSQL, Oracle, SQL Server, and Amazon Aurora.
- **Amazon DynamoDB:** Ultra-fast, single-digit millisecond latency serverless NoSQL key-value and document database.
